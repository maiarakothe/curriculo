# 🚀 Portfólio Pessoal & Acadêmico

Um portfólio web responsivo e interativo desenvolvido para apresentar meus projetos, habilidades técnicas e formas de contato.

- **Site Online:** [Acessar Portfólio](https://maiarakothe.github.io/curriculo/)


## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica (`<header>`, `<main>`, `<section>`, `<footer>`, etc.).
- **CSS3:** Estilização moderna utilizando CSS Variables, Flexbox, Media Queries para responsividade e efeitos de hover.
- **JavaScript (ES6+):** Manipulação de DOM, validação de formulário de contato e animação interativa em Canvas.
